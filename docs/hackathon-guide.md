# CreateOS x Stripe Hackathon — Event Guide

## Overview

CreateOS and Stripe are hosting an online hackathon for builders creating agents that can write and run code. Participants start from an empty directory, set up their stack with Stripe Projects from the command line, and build an agent that runs code safely inside a CreateOS Sandbox.

## Project requirements

Build a new project during the event that:

- Creates an AI agent capable of writing and running code.
- Uses Stripe Projects.
- Runs code safely inside the CreateOS Sandbox.

Both Stripe Projects and the CreateOS Sandbox are required for prize eligibility.

## Submission requirements

Submit through the organizer’s submission form before **5:30 PM Pacific Time**. The submission must include:

- A two- to three-minute demo video hosted on YouTube.
- At least one team member visible on camera in the demo video.
- A public GitHub repository with a README.
- Team and project details.
- A public project announcement on X or LinkedIn.
- A tag for `@createosai` on X, or a mention of CreateOS on LinkedIn.
- The project added to the `projects.dev/leaderboard` using code `CreateOS-2026`.

Submissions missing the video, public repository, on-camera team member, or public post will not be judged.

## Setup checklist

Before kickoff:

1. Have a laptop ready.
2. Create or confirm access to a free Stripe account.
3. Complete the setup checklist in the [CreateOS hackathon guidelines](https://createos.sh/hackathon).
4. Join the event Discord.
5. Decide what agent you want to build.
6. Confirm that your team has no more than three people.
