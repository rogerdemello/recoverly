# Submission Checklist

Complete every item before the **5:30 PM Pacific Time** submission lock.

## Eligibility

- [ ] This is a new project built during the hackathon.
- [ ] The project uses Stripe Projects.
- [ ] The project uses the CreateOS Sandbox.
- [ ] The team has no more than three people.

## Demo video

- [ ] The video is hosted on YouTube.
- [ ] The video is between two and three minutes long.
- [ ] At least one team member is visible on camera.
- [ ] The video demonstrates the project and its working agent.
- [ ] The YouTube link is accessible to the judges.

## Repository

- [ ] The GitHub repository is public.
- [ ] The repository contains a README.
- [ ] The README explains what the project does.
- [ ] The README explains how to run or try the project.
- [ ] The repository link is ready to paste into the submission form.

## Public announcement

- [ ] A public post has been published on X or LinkedIn.
- [ ] The post describes the project.
- [ ] The post tags `@createosai` on X, or mentions CreateOS on LinkedIn.
- [ ] The public post link is ready to paste into the submission form.

## Leaderboard

- [ ] The project has been added to the [projects.dev leaderboard](https://projects.dev/leaderboard).
- [ ] The leaderboard code `CreateOS-2026` has been used.
- [ ] The leaderboard entry is publicly accessible.

## Final submission

- [ ] Team details are complete.
- [ ] Project details are complete.
- [ ] The demo video link is included.
- [ ] The public GitHub repository link is included.
- [ ] The public X or LinkedIn post link is included.
- [ ] The leaderboard entry is included.
- [ ] The form has been submitted before the deadline.
